All Foreign Gifts Around Us

Tangible gifts given to U.S. federal employees by foreign governments, extracted from Federal Register notices.

U.S. law requires federal employees to report gifts of more than minimal value received from foreign governments. The State Department publishes these reports in the Federal Register as dense, unstructured text. This project uses large language models to turn those notices into structured, queryable data: who received what, from whom, when, its estimated value, and what happened to it.

Caveats

  • Some presidential administrations report more promptly and completely than others; gaps in a given year likely reflect reporting delays, not an absence of gifts.
  • Values recorded as ranges (e.g. "$1,000–$1,500") resolve to the low end; vague values ("Unknown", "In appraisal process") are left blank.
  • Donor and recipient names/titles/countries are parsed out of free text by an LLM and may occasionally misparse unusual formatting.
  • When the recipient is an anonymous "Agency Employee," donor details are blanked to preserve that anonymity.

Code

The extraction pipeline (Federal Register → PDF → LLM → database) and this site are built with uv and llm. See the source repository for the code, or its README for how to run the pipeline yourself with Anthropic or a local Ollama model.
